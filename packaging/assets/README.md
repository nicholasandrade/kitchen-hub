# Hub Windows icon

Based on Google's Material Symbols Rounded `space_dashboard`, licensed under Apache-2.0.
Source: https://github.com/google/material-design-icons/blob/master/symbols/web/space_dashboard/materialsymbolsrounded/space_dashboard_48px.svg

The source path is unchanged. Hub adds an off-white fill and a dark slate rounded background with padding. The multi-resolution ICO contains 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel variants. `hub.svg` is the vector master; `space-dashboard-source.svg` preserves the upstream artwork. The license accompanies installed assets.
